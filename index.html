DolphinMod

Ocean‑Powered Scratch Experience

DolphinMod is an experimental, ocean‑themed interface concept inspired by Scratch‑style modding. This repo does not include Scratch source code.

Concept Features
  • • Aqua‑themed UI with glowing ocean gradients
  • • Dolphin‑style branding instead of the classic cat mascot
  • • Hypothetical block palette tuned to motion, waves, and flow
  • • Designed to resemble a mod front page without being a direct fork
